# 塔羅流年國農曆合盤 V0.8

## V0.8
- 拆成兩頁：`index.html` 個人排盤、`pair.html` 雙人合盤，頁首可切換。
- 共用計算程式移到 `core.js`，樣式移到 `styles.css`。

## V0.7
- 新增「雙人合盤」：輸入第二人生日，並排比對兩人的個性、貴人、去年／今年／明年流年、今天的年運／流月／流日；同欄位同牌以金框標示。

## V0.6


- 農曆換算改用壽星天文曆（UTC+8）產生的 `lunar-months.json`，範圍 1900–2100；1900–2099 已與香港天文台資料逐日交叉驗證。取代原本由 Excel「閏月校正」轉出的 `lunar-map.json`。
- 修正：農曆 2 月 29、30 日轉檔錯誤（共 176 天）；原表 1928、1939、1951、1962–63 年各段差一天，以及 1999/04/15、2001/03/24、2046/01/22 的資料錯誤。
- 閏月規則依原表：閏 N 月以 N 月計算，畫面另標示「閏」。
- 牌號換算統一為「超過 21 減 22」（22 對應 0 愚者）。
- 農曆流月、流日使用農曆出生年月日。
- 流日以所選日期的年份計算。
- 新增「你生命中的貴人」（+5）與「你今天的運勢跟心境」。
- 本命欄位名稱改為原表的本性、外顯、內心。
