# 塔羅流年國農曆合盤 V0.5 — 牌意整合測試版

## 更新
- 由原始 Excel「牌意」工作表提取 0–21 共 22 張牌的牌名、牌意、正位、逆位。
- 由「個人特質」工作表提取各牌正面特質、負面特質。
- 國曆與農曆本命、流年、流月、流日同步顯示牌名及可展開的詳細牌意。
- 保留 V0.4 排盤計算，尚未完成公式一致性驗證；牌意與數字對應，不代表計算結果已驗證。

## GitHub Pages
將 index.html、lunar-map.json、tarot-meanings.json 上傳至 Repository 根目錄。
Settings → Pages → Deploy from a branch → main / (root)。
請勿只上傳 index.html，否則日期與牌意資料無法載入。

## 注意
目前是測試版。閏月、本命與流日部分計算仍待原始 Excel 比對，不適合正式收費諮詢。
