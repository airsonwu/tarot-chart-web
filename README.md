# 塔羅流年國農曆合盤 — 可部署網頁測試版 V0.4

## 立即部署

本專案是純靜態網站，無須安裝 Node.js、資料庫或建置流程。

- **Netlify Drop**：解壓縮 ZIP，將整個 `tarot_chart_web_v0_4` 資料夾拖曳到 https://app.netlify.com/drop 。
- **Cloudflare Pages**：建立 Pages 專案，使用直接上傳方式上傳整個資料夾。
- **本機測試**：在解壓縮資料夾執行 `python -m http.server 8000`，然後瀏覽 `http://localhost:8000`。
- **GitHub Pages**：將 `index.html` 和 `lunar-map.json` 放到儲存庫根目錄，啟用 Pages。

**注意：** 不要直接雙擊 HTML 檔案，因為瀏覽器可能禁止 `file://` 讀取同目錄 JSON。

## 已完成

- 可操作的手機/電腦響應式繁體中文網頁。
- 一次輸入國曆生日，同時呈現國曆與農曆，不可切換成單一曆法。
- 原始 Excel「閏月校正」工作表 C/D 欄對照資料提取至 `lunar-map.json`。

- 不需登入即可部署測試；不儲存或上傳使用者生日。
